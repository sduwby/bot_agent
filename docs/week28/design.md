# 第 28 周设计文档 — 首批数据采集与质检

## 1. 概述

**本周目标：** 围绕"夹起螺丝刀并抬离桌面"任务采集首批真机数据集，建立质检与合并流程，产出可用于 ACT 训练的高质量数据集。

**实际完成情况：** 三轮采集（demo / demo_v2 / demo_v3）+ 质检 + 合并，产出 `wangbangyan/demo_v23`（68 集 / 41915 帧）；键盘 Enter 映射加入 `control_utils.py` 以手动控制节奏。验收"50 条高质量成功轨迹、关键字段缺失为 0"达成。

### 1.1 前置依赖

- 第 25 周遥操作链路、第 26 周双相机录制、第 27 周任务与安全 SOP。

## 2. 架构设计

```text
lerobot-record（teleop + 双相机）
   │ ① demo：22 集，螺丝刀固定位置 → 发现模型只会背轨迹
   │ ② demo_v2：螺丝刀位置随机化，私有 Hub 仓库
   │ ③ demo_v3：针对"接近时不张开夹爪"的定向补采
   ▼
质检（自写统计）
   ├─ 每集 action 中 gripper 张开(>12)占比
   ├─ 起始/末尾 wrist 姿态
   └─ 删除任务未完成与异常短的集
   ▼
合并（v2 + v3）
   └─ wangbangyan/demo_v23：68 集 / 41915 帧
      （2 个 task、episode 重编号、index 全局重排）
```

## 3. 数据结构

| 数据集 | 规模 | 说明 |
| --- | --- | --- |
| `wangbangyan/demo` | 22 集 | 螺丝刀固定位置；后发现模型只会背轨迹，弃用 |
| `wangbangyan/demo_v2` | 51 集 / 29506 帧 | 位置随机化，私有 Hub 仓库；质检前 29990 帧，删除 2 集坏数据 |
| `wangbangyan/demo_v3` | 17 集 / 12409 帧 | 定向补采；原采 22 集，质检删 5 集 |
| `wangbangyan/demo_v23` | 68 集 / 41915 帧 | v2+v3 合并：2 个 task、episode 重编号、index 全局重排 |

键盘节奏控制（本周补充）：`control_utils.py` 加入 Enter 映射（同 `→` 结束本阶段）；`episode_time_s`/`reset_time_s` 设为 99999，完全按键推进。

## 4. 接口设计

```bash
# 采集（节奏完全手动：时间预算拉满，Enter/→ 推进、← 重录、Esc 终止）
lerobot-record ... --dataset.repo_id=wangbangyan/demo_v2 \
  --dataset.episode_time_s=99999 --dataset.reset_time_s=99999
```

质检脚本（自写）输入数据集，逐集统计 gripper 张开(>12)占比与起始/末尾 wrist 姿态，输出删除名单；合并脚本执行 episode 重编号与 index 全局重排。

## 5. 数据流

**输入：** 遥操作演示（位置随机化 / 定向补采）。
**处理：** 录制 → 质检（统计指标 + 删除坏集）→ 合并重排。
**输出：** `wangbangyan/demo_v23`（68 集 / 41915 帧），供第 29 周 ACT 训练。

**采集教训：** 元数据与文件不一致会导致 `check_timestamps_sync` 校验失败；删除 episode 时必须同时清理未注册的残留文件。

## 6. 验收

- 50 条高质量成功轨迹；关键字段缺失为 0。

## 7. 实际偏差

1. 第一轮 `demo`（22 集）因螺丝刀位置固定，模型只会背轨迹，整轮弃用；从 v2 起改为位置随机化。
2. `demo` 暴露"接近目标时不张开夹爪"的缺陷分布，追加 v3 定向补采（计划外的一轮）。
3. Enter 映射为采集中途补充（第 25 周仅有 `→`），随 `episode_time_s=99999` 的手动节奏模式一起固化。
