## 3. 实施步骤

1. 确定任务为"夹起螺丝刀并抬离桌面"，单任务、桌面固定工作区。
2. 约定起始姿态=数据集首帧姿态，脚本自动归位。
3. 约定终止条件：固定步数执行 + 末尾保持 300 步（≈10s）后断开；急停=Ctrl+C。
4. 汇编安全要点：`--auto-start` 仅限就绪后、断开松夹爪勿悬空持物断电、过载必须断电重启。
5. 约定每次运行产物写入 `outputs\infer_run_*`（csv + frames），可回放审计。
6. 成文 SOP 并评审。
