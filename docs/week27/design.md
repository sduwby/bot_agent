# 第 27 周设计文档 — 任务与安全协议（SOP）

## 1. 概述

**本周目标：** 固定真机任务定义，固化起始姿态归位、终止条件、急停与安全操作要点，形成书面操作 SOP。

**实际完成情况：** 任务固定为"夹起螺丝刀并抬离桌面"（单任务）；起始姿态=数据集首帧姿态（脚本自动归位）；终止条件=固定步数+末尾保持 300 步（≈10s）后断开；急停=Ctrl+C；运行产物写入 `outputs\infer_run_*` 可回放审计。验收"完成书面操作 SOP"达成（本文档即 SOP）。

### 1.1 前置依赖

- 第 24 周安全事实：`disable_torque_on_disconnect=True` 断开松夹爪；夹爪过载须断电重启。
- 第 25/26 周：遥操作与录制链路可用。

## 2. 架构设计

```text
任务定义：夹起螺丝刀并抬离桌面（单任务，桌面固定工作区）
        │
        ▼
运行协议
   ├─ 起始：脚本自动归位到数据集首帧姿态
   ├─ 执行：固定步数策略
   ├─ 终止：步数用尽 → 末尾保持 300 步（≈10s）→ 断开
   └─ 急停：Ctrl+C
        │
        ▼
产物落盘 outputs\infer_run_*
   ├─ state_action_log.csv（逐步状态/动作）
   └─ frames\（逐帧图像）——可回放审计
```

## 3. 数据结构

- **任务**：单任务，目标物=螺丝刀，成功判据=夹起并抬离桌面。
- **工作区**：桌面固定区域，不越界。
- **运行产物目录**：`outputs\infer_run_<时间戳>\`，含 `state_action_log.csv` 与 `frames\`。

## 4. 接口设计

运行协议关键约定（脚本参数/行为）：

- `--auto-start`：跳过人工确认，**仅限就绪后使用**。
- 起始归位：脚本自动运动到数据集首帧姿态后开始。
- 终止：固定步数 + 末尾保持 300 步（≈10s，30fps）后断开连接。

安全要点（继承第 24 周并固化）：

1. 断开连接会松夹爪（`disable_torque_on_disconnect=True`）——**勿在夹持悬空重物时断电/退出**。
2. 夹爪舵机（id_=6）Overload 过载后必须**断电重启**清除。
3. 急停一律 Ctrl+C，急停后按第 1 条处理夹持物。

## 5. 数据流

**输入：** 归位指令、固定步数预算、相机/关节实时数据。
**处理：** 归位 → 逐步执行并记录 state/action 与帧 → 步数用尽后保持 300 步 → 断开。
**输出：** `outputs\infer_run_*` 下的 `state_action_log.csv` 与 `frames\`，供回放审计。
