## 3. 实施步骤

### 步骤 1：控制数据契约

- 定义 `ControlMode` 枚举。
- 定义三类命令并在构造时校验有限数和维度。
- 定义不可变 `RobotState`、`ControlLimits` 和 `ControlResult`。
- 测试所有非法维度、NaN/Inf、夹爪范围和非正限幅。

### 步骤 2：关节与夹爪控制

- 关节绝对目标先饱和到硬限位，再限制单步关节变化。
- 夹爪绝对位置先饱和到 `[0,1]`，再限制单步变化。
- 结果记录请求、实际应用值、是否限幅和更新后状态。
- 测试大幅命令、多步收敛、硬限位和状态不变量。

### 步骤 3：末端增量控制

- 用 FK 取得当前末端位置。
- 对二维增量做范数限幅。
- 目标位置通过 IK 和当前 seed 转成关节目标。
- 对 IK 关节目标再次执行单步关节限幅。
- 返回实际 FK 末端增量；不可达时返回失败且状态不变。
- 测试增量限幅、关节二次限幅、seed 分支和不可达回滚。

### 步骤 4：固定控制演示

- 从安全的非奇异初始关节状态开始。
- 依次执行关节位置、末端增量和夹爪位置命令。
- 包含超大关节/夹爪请求以触发饱和。
- 包含从伸直状态向工作空间外移动的命令以验证安全拒绝。
- 每一步检查有限状态、硬限位和单步变化，输出 mode、success、clipped 和状态。

### 步骤 5：验证与同步

- 运行 `test_control.py`、控制演示、完整 `pytest` 和 `compileall`。
- 检查 Git 差异，不写入 `runs/` 或缓存。
- 回填设计实际偏差、计划执行状态和总开发计划。
- 全部验收通过后将下一步更新为第 10 周 ManiSkill 入门。
